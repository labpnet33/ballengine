Creator Studio

This is an independent, login-free guest studio built from the public capture. The original BallEngine studio and its private backend are not included in this repository. Preview animations run locally in your browser, and WebM export uses browser recording support.

Music & export

Choose your own audio file. Optional beat-reactive motion uses a local audio analyser.

How to use

Select a mode, tune the controls and add a song if desired. Press Export WebM to record the animation. Audio playback is local; audio is not included in exported files.

For best results, use desktop Chrome or Edge. Some mobile browsers do not support canvas recording.
