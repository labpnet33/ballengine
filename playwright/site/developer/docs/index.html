Developer docs

The reference for the BallEngine developer platform: the website player on your own site, cloud-rendered MP4s from one API call, and Claude or any AI agent making videos through our MCP server. All three use one engine, one account and one set of settings.
Developer platform
Aspect ratios
9:16 (Shorts/Reels/TikTok), 16:9 (YouTube), 1:1 (Square), 4:5, and 3:4.
Your own music
Compose to a mood such as dark phonk, synthwave or chill lofi, or use a track from your own library.
MCP server
A Model Context Protocol server for Claude Desktop, Cursor and other AI agents.

Three ways in, one set of settings

  • Website player: the live simulator on your site with one iframe and a public key. Videos are made on your visitors' devices.
  • Cloud render API: POST /api/v1/videos with a secret key, get an MP4. Paid with render credits.
  • Claude and AI agents: the hosted MCP server, the OpenAPI spec or a ready prompt. Agents call the same API on your credits.

The player and the API read the same look settings with the same names: theme, palette, title_text, watermark_text, speed, ball_count, gravity, sound_effect and config_overrides. They go in the JSON body of a cloud render, in the player's URL, or in its set-settings message, and the same code applies them, so a look you design on your site renders the same in the cloud.

Authentication

Create a secret key on your Developer page and send it as a bearer token on every request. Keys are shown once at creation and can be revoked at any time. Keep them server-side: never ship a key inside a browser or mobile app.

Authorization: Bearer be_sk_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX

API access is invite-only for now: our team switches it on for each account. Buying render credits does not turn it on.

Pricing

Rendering is billed with prepaid credits using linear pricing: 1 credit = 30 seconds of 720p 30 fps video, 2 credits = 30 seconds of 1080p 60 fps (at 720p 30 fps: 15s = 0.5 credits, 45s = 1.5 credits, 60s = 2.0 credits, 300s = 10.0 credits; double each at 1080p 60 fps). You can generate any clip length from 5 seconds up to 5 minutes (300 seconds). Clips shorter than 10 seconds are billed as 10 seconds.

List, page and cancel

GET /api/v1/videos lists the jobs created with your key, newest first, 20 per page by default (up to 100 with limit). When has_more is true, pass next_starting_after as starting_after to get the next page. Filter with status (queued, rendering, done, failed), created_after and created_before (Unix seconds).

GET https://ballengine.app/api/v1/videos?limit=50&status=done&starting_after=job-k3x92ab1c

HTTP 200 OK
{ "jobs": [ ... ], "has_more": true, "next_starting_after": "job-p0q8m2x4a" }

DELETE /api/v1/videos/:id cancels a queued job and refunds its credits in full. A job that has started rendering cannot be canceled (409 already_rendering); delete it once it has finished. Deleting a finished job removes the video file and the job.

DELETE https://ballengine.app/api/v1/videos/job-k3x92ab1c

HTTP 200 OK
{ "id": "job-k3x92ab1c", "deleted": true, "canceled": true, "credits_refunded": 1 }

Webhooks: get notified instead of polling

Register an https URL on your Developer page or through the API. When a render finishes we send it a signed POST with the result. Any 2xx answer within 10 seconds counts as delivered. Anything else is retried after 1 minute, 5 minutes, 30 minutes, 2 hours, 6 hours and 24 hours. An endpoint that fails 20 times in a row is switched off until you turn it back on.

POST https://ballengine.app/api/v1/webhooks
Authorization: Bearer be_sk_...

{ "url": "https://your-server.com/ballengine/webhook", "events": ["video.completed", "video.failed"] }

HTTP 201 Created
{ "id": "we_3f9c...", "url": "...", "events": [...], "status": "active", "secret": "whsec_..." }

The secret is returned once. Other calls: GET /api/v1/webhooks, DELETE /api/v1/webhooks/:id, and POST /api/v1/webhooks/:id/test to send a test event.

Limits and automatic switch-off

  • Test events: 3 per minute and 15 per hour per account. Resends: 5 per minute and 30 per hour. Adding endpoints: 5 per minute and 20 per hour. Going over answers 429 with retry_after.
  • An endpoint is switched off after 20 failed deliveries in a row, or after more than 200 deliveries in one hour.
  • If test or resend calls keep coming after the limit (10 refused calls in an hour), every endpoint on the account is switched off.
  • A switched-off endpoint receives nothing, test events included. Only you can turn it back on, by signing in to your Developer page. There is no API call for it, so a runaway script cannot undo its own switch-off.

A video.failed event carries "status": "failed", an "error" message and "credits_refunded" instead of a download link. The same event can arrive more than once, so use its id to ignore repeats. In the rare case a render reported as failed later finishes, you get a video.completed after the video.failed, and the later one is correct.

Check the signature (Node.js)

import crypto from 'node:crypto';

// rawBody: the request body exactly as received, before JSON parsing.
function verify(rawBody, header, secret) {
  const parts = Object.fromEntries(header.split(',').map((p) => p.split('=')));
  const expected = crypto.createHmac('sha256', secret)
    .update(`${parts.t}.${rawBody}`)
    .digest('hex');
  const fresh = Math.abs(Date.now() / 1000 - Number(parts.t)) < 300;
  const a = Buffer.from(expected);
  const b = Buffer.from(parts.v1 || '');
  return fresh && a.length === b.length && crypto.timingSafeEqual(a, b);
}

Connect Claude, ChatGPT or your own agent

Claude, ChatGPT, Cursor or your own agent can create videos for you. There are three ways to connect them:

  1. 1.

    Copy and paste a prompt

    Nothing to install. Copy the prompt from your Developer dashboard into Claude.ai or ChatGPT.

  2. 2.

    OpenAPI 3.1 spec

    Paste https://ballengine.app/api/v1/openapi.json into Custom GPTs, Make.com, Zapier, or LangChain.

  3. 3.

    Hosted remote MCP

    Point Claude Desktop or Cursor at https://ballengine.app/api/v1/mcp. Nothing to install locally.

The hosted MCP server has the whole platform as tools: generate_video, get_video_status, list_videos, cancel_video, estimate_video_cost, list_simulation_modes, list_visual_themes, list_look_settings, and for the website player get_embed_integration_guide, list_website_players, update_website_player (cloud video limits and websites) and create_cloud_render_token. Send your secret key as a bearer token.

Claude Desktop (claude_desktop_config.json), through the mcp-remote bridge:

{
  "mcpServers": {
    "ballengine": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote", "https://ballengine.app/api/v1/mcp",
        "--header", "Authorization: Bearer ${BALLENGINE_API_KEY}"
      ],
      "env": { "BALLENGINE_API_KEY": "be_sk_YOUR_API_KEY" }
    }
  }
}

Claude Code, Cursor or any client that speaks MCP over HTTP:

claude mcp add --transport http ballengine https://ballengine.app/api/v1/mcp \
  --header "Authorization: Bearer be_sk_YOUR_API_KEY"

Example prompts:

  • "Claude, create a 30s 9:16 TikTok video with a neon cyberpunk theme, dark phonk music, and Ghost Escape mode."
  • "Generate a 15s square video for Instagram with Space Spiral mode and a gold luxury theme."
  • "Check the render status of job-k3x92ab1c."
  • "Add the BallEngine player to my website, with a Cloud video button capped at 20 credits a month."

Website player

Show a BallEngine mode on your own website with one iframe. Visitors randomize it and download the video, made on their own device, counted against your site's monthly videos. The player runs in our frame, so your page's styles never reach it. The public key (be_pk_) only works on the websites we register for it. Invite-only: confirm interest on the developer platform page.

URL options: mode, duration (5 to 60 seconds), visitor (your user's id, for a per-user limit), and every look setting a cloud render takes (the shared settings), with config_overrides as URL-encoded JSON. The look stays on through every Randomize. Change it live with a set-settings message; the player answers settings-changed with the settings it applied and drops any it does not know.

Cloud videos from the player

Like the Studio, the player can offer an HD video made on our GPUs: switch on Cloud videos for the site in your console and the player shows a Cloud video button, or your page starts one with { type: 'cloud-render', quality?, duration? }. It renders the scene on screen and bills YOUR cloud credits (your plan's monthly credits, then bought ones; a paid plan is required), at the API's prices. You set the spend: credits a month for the site, videos a month per visitor (counted by visitor) and the longest length. The player answers cloud-queued, cloud-progress, cloud-done (with url, a signed MP4 link valid 15 minutes, for your server to keep) and cloud-failed (with a code; a failed render is refunded).

To give cloud videos only to the users you choose, such as your paying customers, switch on Only with a token from your server. The built-in button then hides, and each render needs a one-time token (10 minutes) your server mints with your secret key:

POST https://ballengine.app/api/v1/embed/cloud-tokens
Authorization: Bearer be_sk_...

{ "site_key": "be_pk_your_key", "visitor": "USER_ID" }

→ 201 { "token": "be_ct_...", "expires_at": 1761700000, "visitor": "USER_ID" }

// then, on your page:
player.contentWindow.postMessage(
  { target: 'ballengine', type: 'cloud-render', token, quality: '1080p60' },
  'https://ballengine.app');

For a longer or 16:9 video, render the same look from your server with POST /api/v1/videos. Never put a secret key in the page.

Let your AI do it: once invited, press Copy AI prompt on your Developer page and paste it into Claude, ChatGPT or Cursor in your website project. The same guide is at ballengine.app/byobe-guide.txt, and assistants connected to our MCP server get it from the get_embed_integration_guide tool.

<iframe
  src="https://ballengine.app/embed?key=be_pk_your_key&mode=FLAG_BATTLE&visitor=USER_ID&duration=15&theme=cyberpunk_neon&title_text=Who%20escapes%20first%3F"
  style="width: 100%; aspect-ratio: 9 / 16; border: 0"
></iframe>

<script>
  const player = document.querySelector('iframe');
  window.addEventListener('message', (e) => {
    if (e.origin !== 'https://ballengine.app' || e.data?.source !== 'ballengine') return;
    // ready (with e.data.modes for a mode picker) | randomized | mode-changed | settings-changed
    // cloud-queued | cloud-progress | cloud-done (e.data.url) | cloud-failed
    // export-progress | export-done | export-failed | limit-reached
    if (e.data.type === 'export-done') upload(e.data.video); // the MP4 as a Blob
  });
  // Drive the player from your own buttons:
  player.contentWindow.postMessage({ target: 'ballengine', type: 'randomize' }, 'https://ballengine.app');
  // also { type: 'export' }, { type: 'set-mode', mode: 'RHYTHMIC' } and
  // { type: 'set-settings', settings: { theme: 'gold_luxury', speed: 1.5 } }
</script>
